# start-toast-core

Framework-agnostic primitives for [start-toast](https://github.com/stevan-borus/start-toast) — the schema, seal/unseal helpers, and ID generator that any framework adapter can share.

**Not published on npm.** This is a workspace-internal package; its code is bundled into [`react-start-toast`](https://www.npmjs.com/package/react-start-toast) at build time. Future framework adapters can do the same — depend on it via the workspace, inline it at build time.
