# @tanstack/start-toast-core

Framework-agnostic primitives for [start-toast](https://github.com/stevan-borus/start-toast). Powers `@tanstack/react-start-toast` and any future framework adapters.

Most consumers want **[`@tanstack/react-start-toast`](https://www.npmjs.com/package/@tanstack/react-start-toast)** — this package is depended on transitively.
