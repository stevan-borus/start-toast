# @tanstack/react-start-toast

Server-set toast notifications for [TanStack Start](https://tanstack.com/start). React adapter.

```tsx
import { redirectWithSuccess } from '@tanstack/react-start-toast'

await redirectWithSuccess('/dashboard', 'Logged in!')
```

See the [repo README](https://github.com/stevan-borus/start-toast) for setup, recipes, and the full API.
